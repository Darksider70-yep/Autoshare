2. System Architecture & Microservices Blueprint

The system follows a distributed microservices pattern with bounded contexts:

  • User Management Microservice (:8081): Bounded context managing student identity, institutional credentials verification, department categorization, and account lifecycle. Persisted via Spring Data JPA in relational database.
  • Ride & Booking Microservice (:8080): Bounded context managing ride publication, seat reservations, dynamic fare split calculations, and passenger capacity rules.
  • Inter-Service REST Interaction: When a student books a seat, the Ride Service issues a synchronous HTTP GET request (/api/users/verify/{email}) to the User Service to confirm student KYC validity and active account status before finalizing the reservation.

3. Domain Model & JPA Entity Design

The domain model establishes relational constraints, indexing, and audit lifecycle callbacks on the users table: 

@Entity
@Table(name = "users", indexes = {
    @Index(name = "idx_user_email", columnList = "email", unique = true),
    @Index(name = "idx_user_reg_no", columnList = "registrationNumber", unique = true),
    @Index(name = "idx_user_role", columnList = "role"),
    @Index(name = "idx_user_dept", columnList = "department")
})
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)
    private String fullName;

    @Column(nullable = false, unique = true, length = 120)
    private String email;

    @Column(nullable = false, unique = true, length = 30)
    private String registrationNumber; // e.g. RA2411003012297

    @Column(nullable = false, length = 20)
    private String phoneNumber;

    @Column(nullable = false, length = 80)
    private String department;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 30)
    private UserRole role = UserRole.STUDENT_COMMUTER;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 30)
    private AccountStatus status = AccountStatus.ACTIVE;

    @Column(length = 60)
    private String campusGate;

    @Column(length = 100)
    private String hostelOrPG;

    @Column(nullable = false)
    private Double rating = 4.9;

    @Column(nullable = false)
    private Integer totalRidesCount = 0;

    @Column(nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @Column(nullable = false)
    private LocalDateTime updatedAt;

    @PrePersist
    protected void onCreate() {
        this.createdAt = LocalDateTime.now();
        this.updatedAt = LocalDateTime.now();
    }

    @PreUpdate
    protected void onUpdate() {
        this.updatedAt = LocalDateTime.now();
    }
}

6. Inter-Service Microservices Communication

The synchronous REST communication is handled by UserVerificationClient using Spring's RestTemplate with fallback logic: 

@Component
public class UserVerificationClient {
    private final RestTemplate restTemplate;
    private final UserService localUserService; // Graceful in-process fallback

    @Value("${autoshare.userservice.url:http://localhost:8080/api/users}")
    private String userServiceBaseUrl;

    public UserVerificationResponse verifyCommuter(String email) {
        String endpoint = userServiceBaseUrl + "/verify/" + email;
        try {
            UserVerificationResponse response = restTemplate.getForObject(endpoint, UserVerificationResponse.class);
            if (response != null) return response;
        } catch (Exception ex) {
            // Circuit Breaker: fallback to local repository if remote microservice is offline
        }
        return localUserService.verifyUserForRide(email);
    }
}
